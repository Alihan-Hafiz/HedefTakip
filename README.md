# 🎯 Hedef Takip Uygulaması

Bu proje, kullanıcıların kişisel hedeflerini ekleyip ilerleme durumlarını takip edebilecekleri bir web uygulamasıdır.

## 🚀 Özellikler
- Hedef ekleme, düzenleme, silme
- Tema seçimi (Açık, Koyu, Mavi, Yeşil)
- LocalStorage kullanımı (veriler tarayıcıda saklanır)
- Sabitleme (önemli hedefleri üstte tutma)
- İlerleme çubuğu ile dinamik güncelleme

## 🛠️ Kullanılan Teknolojiler
- HTML5, CSS3, Bootstrap 5
- JavaScript (LocalStorage)
